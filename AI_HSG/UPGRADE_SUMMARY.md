## 🚀 如何开始使用新版本

### 方法1：继续使用TXT方式（无需改动）

```bash
# 直接运行，无需修改
python app.py
```

### 方法2：升级到JSON方式（推荐）

```bash
# 1. 修改 app.py 第4行
from hsg_engine_json import HSGEngineJSON as HSGEngine

# 2. 编辑 knowledge/knowledge_base.json 添加内容

# 3. 运行
python app.py
```

### 方法3：使用RAG智能检索（最强大）

```bash
# 1. 安装依赖
pip install sentence-transformers

# 2. 修改 app.py 第4行
from hsg_engine_rag import HSGEngineRAG as HSGEngine

# 3. 运行
python app.py
```

1. 在Header添加Logo图片

}
